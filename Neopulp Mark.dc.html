01
Wordmark & construction
NEOPULP
DASHED = CLEAR SPACE, ONE CAP-HEIGHT ALL SIDESACID RULES = CAP LINE / BASELINE
One word. Never spaced, never camel-cased, never hyphenated. Uppercase in the mark; lowercase “neopulp” in running text, because the goal is a common noun.
Highlight behind PULP only. The insult is the part that gets highlighted. Behind the whole word it reads as decoration and the argument disappears.
Tracking −0.05em, weight 900. The block is padded to the cap-height, bleeding 4% above and below so it reads as ink, not as a UI chip.
Never: outline, drop shadow, gradient, rotation, arched type, or a third colour. Never the acid as type colour.

Three sizes, one geometry: keyline, wordmark left, acid square right, 2px rule, mono block at the foot. Nothing is re-proportioned between sizes — content is removed, never shrunk.
The square never moves and never loses its keyline. It's the only element a reader can identify at 40px, which makes it the actual mark.
Never rotate the stamp. Tilt belongs to the Slopcore campaign, and Slopcore never touches a product.
